ABSTRACT
DRAM–NVM hybrid memory systems address growing ca-
pacity demands by pairing low-latency but capacity-limited
DRAM with high-density but slower non-volatile memory
(NVM). This asymmetry makes page demotion critical: poor
victim selection can increase slow-tier accesses, NVM writes,
and demotion overhead. Existing heuristics are lightweight
but rely on coarse access signals; learning-based cache and
prefetching policies do not directly optimize hybrid-memory
demotion cost. We present CAPD, a lightweight context-
aware page-demotion policy that ranks DRAM candidates
using recent access context and page states. CAPD is trained
offline with replay-derived rankings from future inactiv-
ity, coldness, write sensitivity, and demotion cost, and is
invoked only at demotion events. On real traces, CAPD re-
duces weighted replay cost under DRAM capacity pressure,
including a 10.83% reduction over the best classical baseline
on thestreamclusterpressure window.
1 INTRODUCTION
With the growth of data-intensive applications such as ma-
chine learning, graph analytics, and in-memory analytics,
modern systems increasingly demand larger main-memory
capacity and higher memory performance [4, 24, 30]. How-
ever, DRAM scaling has become increasingly constrained,
while non-volatile memory (NVM) provides higher density
and lower cost per bit but suffers from higher write latency
and limited write endurance [3, 7, 8, 13, 17, 19, 29, 31]. There-
fore, DRAM–NVM hybrid memory systems, which combine
low-latency DRAM with high-density NVM, have emerged
as an important main-memory architecture [1, 7, 16, 19–21].
In such systems, DRAM typically serves as a fast tier for
hot and write-sensitive pages, while NVM provides a large-
capacity tier for colder pages [ 1, 15, 16, 20, 21]. Since the
DRAM tier is capacity-limited, the system requires demot-
ing some DRAM-resident pages to NVM to preserve this
placement goal; poor victim selection can increase access
latency, amplify NVM write traffic, and accelerate device
wear [7–10, 22, 28, 29, 31].
Traditional replacement policies based on fixed heuristic
rules, such as LRU, LFU, and CLOCK, often struggle with
dynamic access behavior [2, 9]. Learning-based approaches
can improve adaptability by exploiting access history and
program context [5, 12, 23, 25], but many target cache hit rate
or prefetching rather than write sensitivity and the cost of
demoting pages from DRAM to NVM, while longer-history
models may incur nontrivial online overhead due to large
history windows or complex inference [12, 18, 23].
To address these limitations, we present CAPD, a light-
weight context-aware page demotion policy for hybrid
DRAM–NVM memory systems. CAPD encodes recent access
records using physical addresses, program counters (PCs),
and read/write flags, then lets each DRAM candidate extract
candidate-specific context for demotion scoring.
In summary, this paper makes the following contributions:
• We formulate DRAM page demotion in hybrid mem-
ory as a cost-aware candidate-page ranking problem,
enabling CAPD to select victims by comparing DRAM-
resident candidates using recent access context and
page-level states.
• We design a lightweight access-sequence encoder and
candidate-aware scoring mechanism that generates
demotion-priority scores from recent access context
and page-level representations.
• We construct cost-aware reference rankings with of-
fline replay and evaluate CAPD on real memory traces,
showing cost reductions under DRAM capacity pres-
sure and workload-dependent boundary cases.
2 BACKGROUND AND MOTIV ATION
2.1 Cost-Aware Page Demotion
Beyond the basic DRAM–NVM tiering described above, the
key policy question is which DRAM-resident page should be
demoted under DRAM capacity pressure [1, 10, 14, 20, 21].
This decision directly affects both performance and NVM
write overhead: demoting soon-reused or write-intensive
pages can increase slow-tier accesses and costly NVM
writes [9, 11, 20]. Demotion can also consume memory band-
width and incur page-management overhead [ 21, 26, 28].
Therefore, DRAM-to-NVM demotion in hybrid memory
should not be reduced to a simple recency- or frequency-only
victim-selection problem.
2.2 Context-Aware Candidate Ranking
Traditional policies such as LRU, LFU, and CLOCK are effi-
cient, but they rely on fixed heuristics and reduce page be-
havior to simple signals such as recency or frequency [2, 6, 9].
Two pages with similar recency or frequency can still have
very different demotion costs: one may be read-only and

Learning-based policies can use access history to improve
adaptivity, but they must remain lightweight enough for
demotion-time decisions [12, 23, 25]. Modeling long histories
or scoring each candidate against the full access sequence can
introduce nontrivial online overhead [12, 18, 23]. At the same
time, using only address sequences may miss useful signals
from the program counter and read/write type [5, 9, 27].
These observations motivate a lightweight context-aware
ranking formulation: at each demotion point, the policy
should use recent access context and page-level states to
rank the current DRAM candidates and demote the page
with the highest demotion priority. CAPD follows this direc-
tion by learning a cost-aware candidate-page ranking policy
for DRAM-to-NVM demotion.
3 DESIGN
3.1 Overall Framework
Figure 1 illustrates the overall framework of CAPD. CAPD
treats DRAM page demotion as a context-aware candidate
ranking problem. It consists of four components: Multi-
dimensional Feature Construction, Lightweight Access Se-
quence Encoding, Candidate-Aware Context Scoring and
Demotion Decision, and Cost-Aware Ranking Optimization.
It encodes recent accesses with a lightweight Transformer,
lets each candidate page query the encoded sequence to
obtain a candidate-specific context, and scores the context
for demotion. Training uses offline trace replay to derive a
cost-aware ranking objective.

4 EV ALUATION
4.1 Experimental Setup
We evaluate CAPD using trace replay on PARSEC-derived
memory traces. Each trace is split chronologically into train-
ing, validation, and test windows, and all reported results use
the held-out test window. Unless otherwise stated, the DRAM
tier holds 16 pages, the history length is 10, the eviction can-
didate set contains 8 pages, and the prediction lookahead is
256 accesses.

4.2 Main Results
Figure 2 summarizes the main replay results. CAPD improves
the weighted cost on workloads where replacement deci-
sions expose a real tradeoff between hit rate, writes, and
migrations. On streamcluster-pressure, CAPD reduces nor-
malized cost by 10.83% over the best classical baseline and
by 18.93% over the best learned baseline. On blackscholes,
CAPD slightly improves over both groups of baselines. On
dedup-pressure, the trace has very high locality under the
tested configuration, so CAPD ties the best classical and
learned policies.
Table 1 gives the same comparison in absolute weighted
cost. The strongest result is on streamcluster-pressure, where
CAPD reduces migrations from 8937 under CLOCK to 5981
while also increasing the hit rate from 95.52% to 97.00%. This
shows that CAPD is not merely reducing writes by sacrificing
locality; it learns eviction choices that jointly reduce NVM
reads, NVM writes, and migrations. On blackscholes, CAPD
is close to LFU in hit rate but writes substantially fewer
NVM pages, leading to a small overall cost reduction. On
dedup-pressure, almost all competitive policies converge to
the same behavior, leaving little room for improvement.
4.3 Capacity Sensitivity
We next vary the DRAM capacity on streamcluster-pressure,
the workload with the clearest memory-pressure behavior.
This experiment tests whether CAPD only wins at a single
cache size or remains useful across pressure levels.
Table 2 shows that CAPD is most useful when DRAM
pressure is high. With 8 and 16 DRAM pages, it reduces
weighted cost by about 10% relative to the best rule-based
policy. With 32 pages, the miss stream shrinks substantially
and replacement decisions become less consequential; CAPD
then converges to near parity with the best classical baseline.
This behavior is expected for a learned eviction policy: its
advantage appears when the cache is small enough that
choosing the wrong victim causes repeated NVM accesses
or migrations.

4.4 Stability and Robustness
Because CAPD is trained, we also check whether the main
result depends on a single random seed. On streamcluster-
pressure, three independent training seeds all beat the best
classical baseline, with cost reductions ranging from 10.69%
to 11.71% and a mean reduction of 11.08%. On blackscholes,
the result is closer to parity: two seeds slightly beat LFU,
while one seed is 2.66% worse, giving a mean delta of +0.24%.
We therefore treat blackscholes as a near-tie workload rather
than as the primary evidence for CAPD’s benefit.
We also reweight the dominant pressure case under al-
ternative cost models. On streamcluster-pressure, CAPD
remains better than the best classical baseline under mild,
write-heavy, and migration-heavy cost settings, with reduc-
tions from 6.98% to 15.91%. This suggests that the result is
not an artifact of a single hand-picked write or migration
weight.
4.5 Discussion
The results support two conclusions. First, cross-attention
over the encoded history is useful when eviction decisions
must balance recency, write behavior, and migration cost
under memory pressure. Second, CAPD is not designed to
dominate every trace regime. When locality is already cap-
tured by a simple policy, as in dedup-pressure, CAPD cor-
rectly falls back to near-identical behavior; when a workload
is near parity, as in blackscholes, training seed and small
replay differences can change the ranking. The main benefit
appears in pressure regimes where rule-based policies make
avoidable migration-heavy eviction choices.
5 CONCLUSION
This paper presented CAPD, a lightweight context-aware
DRAM page eviction policy for DRAM–NVM hybrid memory
systems. CAPD formulates victim selection as a candidate-
page ranking problem, combining multi-dimensional access
context from physical addresses, program counters, and
read/write flags with lightweight page-level states. Offline
trace replay is used to construct cost-aware reference rank-
ings, while online inference is invoked only at eviction points.
Our evaluation on real PARSEC traces shows that CAPD can
reduce weighted replay cost under replacement pressure,
with the strongest improvement on streamcluster, while also
revealing important boundary cases such as canneal. These
results suggest that context-aware ranking is a promising di-
rection for hybrid-memory page eviction, but also highlight
the need for better candidate selection and lower-overhead
runtime implementation.
